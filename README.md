# usepier Homebrew tap

Formulae for [pier](https://github.com/usepier/pier).

```
brew install usepier/tap/pier
```

Previously installed from `kerem-kaynak/tap`? Migrate with:

```
brew untap kerem-kaynak/tap && brew install usepier/tap/pier
```

(If you also use `wt` from that tap, keep it and run
`brew uninstall pier && brew install usepier/tap/pier` instead.)
